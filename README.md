# 🔍 فلزیاب | Metal Detector

## 📱 نحوه نصب روی تبلت Galaxy Tab A9

### مرحله 1: دانلود APK
1. برو به [Releases](../../releases)
2. آخرین APK رو دانلود کن
3. فایل `metaldetector.apk` رو روی تبلت کپی کن

### مرحله 2: نصب
1. روی تبلت فایل APK رو باز کن
2. اگر پیغام امنیتی دیدی، "Install anyway" رو بزن
3. صبر کن تا نصب تمام شود

### مرحله 3: دسترسی‌ها
هنگام اولین اجرا، برنامه درخواست می‌کند:
- ✅ دوربین - تایید کن
- ✅ موقعیت (GPS) - تایید کن
- ✅ میکروفون - تایید کن
- ✅ سنسورها - تایید کن
- ✅ صدا - تایید کن

**تمام مجوزها را تایید کنید تا برنامه کار کند!**

## 🎮 نحوه استفاده

1. برنامه رو باز کن
2. منطقه رو انتخاب کن
3. دکمه "▶️ شروع" رو بزن
4. برنامه شروع به جستجو می‌کند
5. هنگام تشخیص فلز، بوق می‌شنوی
6. نتایج رو ببین: نوع، عمق، مختصات

## 🔧 سنسورهای دستگاه

برنامه از این سنسورها استفاده می‌کند:
- 📷 دوربین
- 📡 GPS
- 🎤 میکروفون
- 📐 شتاب‌سنج (عمق یابی)
- 🧭 قطب‌نما (تشخیص فلزات)
- 🔄 ژیروسکوپ (زاویه یابی)
- 🔵 فشارسنج (ارتفاع)
- 💡 سنسور نور
- 🌡️ دماسنج

## 📊 نمایش داده‌های سنسور

دکمه "📊 سنسورها" رو بزن تا تمام داده‌های زنده سنسورها رو ببینی.

## 🐛 رفع مشکل

اگر برنامه کار نمی‌کند:
1. دستگاه رو ریست کن
2. تمام دسترسی‌ها رو تایید کن
3. برنامه رو حذف کن و دوباره نصب کن

## 📧 پشتیبانی

اگر مشکلی داشتی، issue باز کن.
